# 全景图查看器 — Panorama Viewer

基于 Three.js 的纯前端 360° 全景图查看器，支持拖拽旋转、滚轮缩放、上传自定义全景图。

## 功能特性

- **360° 全景浏览** — 鼠标拖拽 / 触屏滑动旋转视角，滚轮 / 双指缩放
- **三图槽位切换** — 底部工具栏支持 3 张全景图之间一键切换
- **固定全景图** — 槽位 1 预置一张 DJI 无人机航拍全景图（不可删除）
- **本地上传** — 槽位 2、3 支持点击上传自己的全景图片，支持删除替换
- **键盘操控** — 方向键旋转视角，R 键重置视角
- **响应式设计** — 适配桌面端和移动端

## 部署方式

### GitHub Pages

1. 进入仓库 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`
3. **Branch** 选择 `main`，文件夹选择 `/ (root)`
4. 点击 **Save**，等待 1-2 分钟部署完成
5. 访问 `https://ZJH0601.github.io/QJ_WY/`

### 本地运行

直接用浏览器打开 `index.html`，或使用任意静态服务器：

```bash
npx serve .
# 或
python -m http.server 8080
```

## 技术栈

- [Three.js](https://threejs.org/) — 3D 渲染引擎，球体等距柱状投影实现全景
- 纯 HTML/CSS/JS，零依赖构建工具
- GitHub Pages 一键部署

## 使用说明

1. 打开页面后，默认显示预置的全景图（槽位 1，带「固定」标记）
2. **拖拽鼠标** 或 **手指滑动** 可以环顾四周
3. **滚动滚轮** 或 **双指捏合** 可以缩放视野
4. 点击底部空槽位（+号）上传自己的全景图
5. 点击已加载的槽位切换到对应全景
6. 点击上传槽位右上角 × 号可删除图片
7. 按 **R 键** 或点击顶部时钟图标重置视角

## 支持的图片格式

JPEG、PNG、WebP、BMP。建议使用 **等距柱状投影 (equirectangular)** 格式的全景图（宽高比 2:1），以获得正确的 360° 显示效果。
